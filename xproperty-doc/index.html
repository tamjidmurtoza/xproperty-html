Xproperty Documentation

Thank you for choosing Xproperty, a real estate and property listing HTML template built with Bootstrap 5, SCSS and jQuery. This guide covers setup, customisation and every component the template ships with.

Requirements

Xproperty is plain HTML, CSS and JavaScript, so there are no server requirements. You only need:

  • A code editor, such as VS Code.
  • A modern web browser to preview pages.
  • Optional: Dart Sass (or Node.js) if you want to edit the SCSS source.
  • Any web hosting that serves static files to go live.

Installation

  1. Unzip the package you downloaded.
  2. Open index.html (or any other page) in your browser to preview it.
  3. Edit the HTML in your code editor. Styles live in assets/css/style.css and scripts in assets/js/main.js.
  4. Replace the demo text and images with your own content.

Use a local server such as the VS Code Live Server extension while you edit. The page reloads automatically on save, and embedded maps and videos behave the same as they will online.

Deployment

Upload the contents of the template folder (all .html files and the assets folder) to your hosting's public directory, usually public_html or www. Keep the folder structure unchanged so relative paths keep working.

You can also deploy for free on static hosts such as Netlify, Vercel, GitHub Pages or Cloudflare Pages by dragging in the folder or connecting a Git repository.

Before going live, replace the demo Web3Forms access key in your forms (see Contact Form) and remove pages you don't use from the navigation menu.

HTML Structure

Every page follows the same skeleton: preloader, header, page sections and footer. CSS loads in the <head> and scripts load just before </body>.

<body>
  <div class="cs_preloader">…</div>                     <!-- Preloader -->
  <header class="cs_site_header cs_sticky_header …">…</header>

  <section>…</section>                                   <!-- Page sections -->

  <footer class="cs_footer …">…</footer>

  <script src="assets/js/jquery.min.js"></script>
  <!-- plugin scripts … -->
  <script src="assets/js/main.js"></script>
</body>

Sections are self-contained. You can copy a section from one page to another as long as the target page loads the same plugin files.

Preloader

The preloader fades out once the page has loaded. To remove it, delete the cs_preloader block from the page.

Logo & Favicon

The logo is an <img> inside .cs_site_brand in the header (and again in the footer). Replace the file or point the src to your own logo:

<a href="index.html" class="cs_site_brand">
  <img src="assets/img/logo.svg" alt="Your Company">
</a>

Replace assets/img/favicon.png with your own icon (a square PNG, 32×32 or larger) to update the browser-tab icon on every page.

Colors

All colors are CSS variables at the top of assets/css/style.css (source: assets/sass/default/_variable.scss). Change a value once and the whole site updates.

--accent-color#00CC61
--primary-color#1D1D1D
--secondary-color#434343
--border-color#D1D1D1
--gray-color#E2E2E2
--gray2-color#F9F4F1
--gray3-color#FAFAFA
--gray4-color#FFFAF6
--danger-color#FF0000
:root {
  --accent-color: #00CC61;      /* brand color: buttons, links, highlights */
  --primary-color: #1D1D1D;     /* headings and dark buttons */
  --secondary-color: #434343;   /* body text */
  --border-color: #D1D1D1;
}

Fonts

The template uses Cabin for headings, Raleway for body text and Carattere for decorative script text. They're loaded from Google Fonts with an @import at the top of style.css (_typhography.scss in SCSS).

  1. Pick your fonts on Google Fonts and copy the embed URL.
  2. Replace the @import url(…) line at the top of style.css.
  3. Update the font variables:
:root {
  --primary-font: "Cabin", sans-serif;      /* headings */
  --secondary-font: "Raleway", sans-serif;  /* body text */
  --ternary-font: "Carattere", cursive;     /* decorative */
}

Dark Version

Add the cs_dark class to <body> to switch a page to the dark palette. It redefines the color variables, so every component follows automatically. single-property-v1.html and single-property-v2.html are examples.

<body class="cs_dark">

Edit the dark palette in the .cs_dark { … } block of _variable.scss (or style.css).

SCSS

SCSS is optional. assets/sass/style.scss imports every partial in this order: variables, typography, spacing, general, header, footer, sidebar, slider, video modal, preloader, then the component partials and the dark version. Compile it to assets/css/style.css with Dart Sass:

npx sass assets/sass/style.scss assets/css/style.css --watch

Compiling overwrites style.css. Pick one workflow: edit either the SCSS or the CSS, not both.

Images & Backgrounds

Images are in assets/img. The simplest way to swap one is to replace the file with your own image of the same name and similar dimensions.

Background images

Any element with a data-src attribute gets that image as its CSS background. Add cs_bg_filed to make it cover the element.

<section class="cs_hero cs_bg_filed" data-src="assets/img/hero-bg-1.jpg">…</section>

Icons

The full Font Awesome 6 Free set is included (solid, regular and brands). Copy an icon's class name from their site:

<i class="fa-solid fa-house"></i>
<i class="fa-regular fa-heart"></i>
<i class="fa-brands fa-facebook-f"></i>

Header & Menu

The header has three areas: cs_main_header_left (logo), cs_main_header_center (navigation) and cs_main_header_right (language, login and call-to-action).

  • Sticky header: keep cs_sticky_header on <header> and it gets cs_sticky_active once the page scrolls. Remove the class to keep the header static.
  • Dropdowns: add menu-item-has-children to an <li> that contains a nested <ul>. On mobile, a toggle arrow is added automatically.
  • Mobile menu: the hamburger button is generated by main.js. No extra markup is needed.
<li class="menu-item-has-children">
  <a href="#">Listing</a>
  <ul>
    <li><a href="property-listing-buy.html">Buy</a></li>
    <li><a href="property-listing-rent.html">Rent</a></li>
  </ul>
</li>

Sliders

Sliders use Slick and are configured with data attributes on .cs_slider_container, so no JavaScript changes are needed. Each slider lives inside a .cs_slider wrapper.

<div class="cs_slider">
  <div class="cs_slider_container"
       data-autoplay="0" data-loop="1" data-speed="800"
       data-center="0" data-variable-width="0"
       data-slides-per-view="responsive"
       data-xs-slides="1" data-sm-slides="2" data-md-slides="2"
       data-lg-slides="3" data-add-slides="3">
    <div class="cs_slider_wrapper">
      <div class="cs_slide">…</div>
      <div class="cs_slide">…</div>
    </div>
  </div>
  <div class="cs_left_arrow">…</div>   <!-- optional arrows -->
  <div class="cs_right_arrow">…</div>
  <div class="cs_pagination"></div>     <!-- optional dots -->
</div>
AttributeValuesDescription
data-autoplay0, 1 or msOff, on (3s), or a custom delay in milliseconds such as 5000.
data-loop0 / 1Infinite loop.
data-speedmsTransition speed.
data-center0 / 1Center mode with partial side slides.
data-variable-width0 / 1Slides keep their own width.
data-fade-slide0 / 1Fade between slides instead of sliding.
data-slides-per-view1 or responsiveUse responsive to enable the breakpoint attributes below.
data-add-slidesnumberSlides on screens ≥ 1400px.
data-lg-slidesnumberSlides below 1400px.
data-md-slidesnumberSlides below 1200px.
data-sm-slidesnumberSlides below 992px.
data-xs-slidesnumberSlides below 768px.

Add a .cs_slider_number element inside .cs_slider to show a “1 / 5” slide counter.

Tabs

Each tab link's href points to the id of its panel. The active class marks the open tab and panel.

<div class="cs_tabs">
  <ul class="cs_tab_links cs_style_1">
    <li class="active"><a href="#sale">For Sale</a></li>
    <li><a href="#rent">For Rent</a></li>
  </ul>
  <div class="cs_tab_body">
    <div class="cs_tab active" id="sale">…</div>
    <div class="cs_tab" id="rent">…</div>
  </div>
</div>

Accordion

Used on the FAQ page. Add active to the item that should start open. Opening one item closes the others.

<div class="cs_accordian cs_style_1 active">
  <div class="cs_accordian_head">
    <h3 class="cs_accordian_title">Your question?</h3>
    <span class="cs_accordian_toggler"></span>
  </div>
  <div class="cs_accordian_body">Your answer.</div>
</div>

Image Gallery

Links with cs_gallery_item inside a .cs_gallery_list open in a lightGallery lightbox with zoom, fullscreen and swipe. The link's href is the full-size image.

<div class="cs_gallery_list">
  <a href="assets/img/kitchen.jpg" class="cs_gallery_item">
    <img src="assets/img/kitchen.jpg" alt="Kitchen">
  </a>
  <a href="assets/img/bed-room.jpg" class="cs_gallery_item">
    <img src="assets/img/bed-room.jpg" alt="Bedroom">
  </a>
</div>

Thumbnails are turned off. To show them, set thumbnail: true in the lightGallery() function of main.js.

Video Popup

Add cs_video_open to a link whose href is a YouTube embed URL. Clicking it plays the video in a popup.

<a href="https://www.youtube.com/embed/VIDEO_ID" class="cs_video_open">Play video</a>

Counters & Ratings

Animated counter

Odometer counts up to data-count-to when the number scrolls into view.

$<span class="odometer" data-count-to="50"></span>B+

Star rating

Set data-rating from 0 to 5. Decimals such as 4.5 work too.

<div class="cs_rating" data-rating="4.5">
  <div class="cs_rating_percentage"></div>
</div>

Selects & Date Pickers

Any <select> with the tom_select class becomes a styled Tom Select dropdown.

<select class="tom_select">
  <option selected disabled>Status</option>
  <option value="sale">For Sale</option>
  <option value="rent">For Rent</option>
</select>

Flatpickr is attached to inputs with id="datePicker" (date) and id="timePicker" (time). Change the date format in the dateTimePicker() function of main.js.

<input type="text" id="datePicker" placeholder="Select Date">
<input type="text" id="timePicker" placeholder="Select Time">

Pricing Toggle

The monthly/yearly switch on pricing.html shows elements with monthlyPrice / monthlyText or yearlyPrice / yearlyText. Edit both values for each plan:

$<span class="monthlyPrice">199</span><span class="yearlyPrice">1990</span>

Contact Form

Forms with id="cs_form" are sent with AJAX to Web3Forms, a free form backend that needs no server code. The response message appears in #cs_result.

  1. Create a free access key at web3forms.com using the email address that should receive messages.
  2. Paste the key into the hidden access_key input of each form.
  3. Make sure the form contains an element with id="cs_result" for the status message.
<form id="cs_form" class="cs_contact_form">
  <input type="hidden" name="access_key" value="YOUR_ACCESS_KEY">
  <input type="text" name="name" placeholder="Name" required>
  <input type="email" name="email" placeholder="Email" required>
  <textarea name="message" placeholder="Message"></textarea>
  <button type="submit">Send</button>
  <div id="cs_result"></div>
</form>

Replace the demo access key before going live, or messages won't reach your inbox.

Google Map

Maps are standard Google Maps embeds. To show your location:

  1. Search for your address on Google Maps.
  2. Click Share → Embed a map and copy the URL inside src="…".
  3. Replace the src of the map <iframe> on the page.

Language Switcher

The header includes a flag dropdown (EN, DE, ES, CN, AR, BD) built with flag-icon CSS. It's a UI component only: connect each option to your translated pages or i18n solution.

To add a language, copy a button in .cs_language_dropdown and change the flag-icon-xx class (two-letter country code) and data-lang value.

Animations & Scrolling

Scroll animations (AOS)

Elements animate in when they have a data-aos attribute. See the AOS docs for all effects.

<div data-aos="fade-up" data-aos-delay="100">…</div>

To disable all scroll animations, remove aosInit(); from the init list in main.js and delete the data-aos attributes.

Smooth scrolling (Lenis)

Lenis adds inertial smooth scrolling. To use the browser's native scrolling, remove smoothScroll(); from the init list in main.js.

Script order

Keep jQuery first and main.js last. If you remove a plugin file from a page, also remove its initialisation call from main.js, or the browser console will show an error.

Browser Support

Xproperty supports the latest versions of Chrome, Firefox, Safari and Edge on desktop and mobile. Internet Explorer is not supported.
