FAQ

Frequently Asked Questions

Everything you need to know before getting started with Xproperty.

What do I get with Xproperty?

You get 10 homepage demos, 23 inner pages (listings, property details, agents, blog, pricing, FAQ, contact, auth pages and a user dashboard), all CSS/SCSS source files, JavaScript, fonts and icons.

Do I need a build tool to use it?

No. Xproperty is plain HTML, CSS and JavaScript. Open any page in your browser and start editing. If you prefer SCSS, the source files are included so you can compile with any Sass tool.

Can I change the colors and fonts?

Yes. Colors and fonts are defined as CSS variables at the top of the stylesheet (e.g. --accent-color, --primary-font). Change them once and the entire site updates.

Can I integrate it with WordPress, Laravel or React?

Absolutely. The clean, component-like markup makes it straightforward to convert into templates for any CMS or framework of your choice.

Is the template mobile friendly?

Every page is fully responsive and tested across modern browsers and device sizes, from small phones to large desktop displays.

Is there a dark version?

Yes. Add the cs_dark class to the <body> tag and the page switches to the dark palette. See the Single Property demos for examples.

Does the contact form work without a backend?

Yes. Forms are sent with AJAX to Web3Forms. Create a free access key, paste it into the form and messages arrive in your inbox — no PHP or server setup needed.

Is documentation included?

Yes. The package includes HTML documentation covering setup, file structure, colors, sliders, forms and scripts. Open the documentation.
